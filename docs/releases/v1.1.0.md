# 网络工具箱 1.1.0

首个正式 GitHub Release，支持 **Android 8.0 及以上**。

## 本版功能

- 共 26 项工具，手机和平板统一为“本地测、测速、扫描、IP/MAC、我的”五个入口。
- 按已提供的参考截图重做三列首页、蓝紫渐变诊断入口、深浅主题及终端式结果区。
- 提供真实 ICMP Ping、TTL 路由追踪、一键诊断、TCP/UDP、HTTP 与证书检查。
- DNS 支持记录类型、公共和自定义服务器；系统与直接 UDP 查询的区别在应用中说明。
- 增加下载、上传、延迟、抖动、分类站点检测，以及局域网扫描、Bonjour/SSDP 服务发现。
- 保留 IP/MAC、子网、WOL、编码、摘要、收藏、本机历史和结果分享。

下载附件 **network-toolkit-1.1.0-debug.apk**，允许相应来源安装应用后安装。此附件与此前通过验收的 1.1.0 APK 完全一致，保留同一签名，未重新构建或换签。


## 验证与范围

79 项 JVM 单元测试、20 项 Android 设备回归及 1 项一键诊断专项通过；Lint 无问题，GitHub CI 构建通过。21 个不同设备用例按完整回归和专项分次执行，详细记录见源码中的 `docs/VALIDATION.md`。
