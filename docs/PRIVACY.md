# 隐私说明

适用版本：网络工具箱 1.1.0。

应用无需账号，不含广告或分析 SDK，不向开发者上传检测历史。网络功能由你主动启动；不会自动开始测速、扫描或遍历分类站点。

## 本机数据

收藏、主题、DNS 设置、自定义站点和最近检测历史保存在应用私有目录。历史默认开启，最多 50 条，输入及结果分别设有长度上限（结果约 16 KiB）；可能包含你输入的域名、IP、网址参数、文本和收到的网络响应。可关闭新增历史并清空已有记录，自定义站点可单独删除。卸载应用会删除本机数据。

应用关闭 Android 云备份，并在支持的 Android 版本中排除设备迁移数据。复制操作使用系统剪贴板；分享操作将结果交给你在系统分享面板选择的应用。

## 网络目的地与数据

| 功能 | 请求目的地与数据 |
| --- | --- |
| 公网 IPv4 | 主动请求 `https://api.ipify.org`；服务会看到你的出口 IPv4，纯 IPv6 网络可能不可达 |
| 网速测试 | 默认 GET `https://speed.cloudflare.com/__down`、POST `https://speed.cloudflare.com/__up`；上传的是程序生成的测试字节，不读取你的文件或照片 |
| 分类站点延迟 | 仅在开始批量测试或点击卡片后，对列出的站点发送 HTTPS HEAD；支持自定义站点 |
| DNS | 系统 A/AAAA 使用 Android 解析器；选择公共/自定义 DNS 或查询其他记录类型时，向实际选择的 DNS 发送 UDP 53 查询 |
| Ping、Traceroute、TCP、UDP、HTTP、证书 | 连接你输入的目标，传输相应协议所需的数据；UDP 文本与 HTTP 目标由你指定 |
| 局域网扫描 | 向你确认的私有/链路本地 IPv4 网段发起探测，最多 256 个地址；设备与 MAC 信息仅在平台可提供时显示 |
| Bonjour / SSDP | 在当前局域网使用 Android NSD 和 SSDP M-SEARCH 发现服务，多播与收到的服务信息可能暴露当前设备的网络存在 |
| IP/MAC 查询 | IP/域名解析和可用反向名称使用系统 DNS；MAC 格式/OUI 前缀/标志在本地分析，不提交地理位置、运营商或厂商查询服务 |

所有远端服务会看到连接来源及协议本身包含的数据，并适用其各自的隐私政策。选择公共或自定义 DNS 意味着把查询域名交给该 DNS 服务；**直接 UDP 53 查询没有 DNS 加密，不会继承 Android 私密 DNS/DoT 设置，也不是 DoH**。系统解析器可能使用 DNS 缓存。

测速开始前会明确提示流量并要求确认。默认约 5 MB 下载 + 1 MB 上传，可选择更大的下载样本；失败或取消前已经传输的数据、协议开销及网络缓冲仍可能计入流量。HEAD 延迟包含建连及服务端响应，属于实际网络请求，不等于 ICMP。

Base64、URL 编码、摘要与子网计算在本地执行。WOL 向指定局域网广播地址发送魔术包。应用不把未经测量的示例数据、厂商或地理位置填入结果。

## 权限与传输安全

仅声明 INTERNET、ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE、CHANGE_WIFI_MULTICAST_STATE。新增的 Wi-Fi 多播权限用于局域网服务发现，不申请 GPS/位置、通讯录或存储权限；受位置或系统访问限制的信息保持未知。

HTTPS 始终使用 Android 系统信任及主机名校验，不绕过自签名、过期或不匹配证书。HTTP 检测为诊断旧服务支持不加密的 HTTP，请勿在明文请求中传输敏感内容。UDP、ICMP、WOL 与局域网发现协议本身不提供 HTTPS 式加密。
