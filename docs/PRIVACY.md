# 隐私说明

网络工具箱 1.0.0 不需要账号，不含广告或统计 SDK，不向开发者上传使用记录。

设备中的收藏、主题偏好和最近检测历史保存在应用私有目录。Android 云备份已关闭。历史默认开启，最多保存 50 条，可能含你输入的主机、网址、文本及检测结果。可在设置关闭新增记录，并清空已有记录；卸载应用会删除本机数据。

网络请求仅由主动操作触发：公网 IP 查询连接 api.ipify.org；测速默认连接 speed.cloudflare.com，也可输入其他 HTTPS 下载地址；其余工具连接输入的目标，DNS 使用系统解析器。目标服务会看到请求来源 IP 及协议本身包含的数据，适用各服务自己的隐私政策。默认测速下载 5 MB，最多读取 10 MiB；连接和协议开销也可能计入运营商流量。

Base64、URL 编码、摘要和子网计算均在本地完成。复制操作使用 Android 剪贴板；系统及有权限的其他应用可能读取剪贴板。分享操作将结果交给你在系统分享面板选择的应用。

HTTPS 保持 Android 系统信任与主机名验证。HTTP 检测工具支持不加密的 HTTP，仅供诊断；请勿通过明文请求传输敏感内容。
