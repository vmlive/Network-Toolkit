原生诊断使用 5 个固定 HTTPS 来源：ipify IPv4、ipify IPv6、IP.SB、Cloudflare Trace、Ping0 当前出口。它们独立返回成功或错误，归属字段来自服务实际响应，可能与其他数据库不同。多来源 IP 差异不是 VPN/泄漏证明；Cloudflare WARP 字段只表达该服务返回的 WARP 状态；本地接口地址查询也不冒充 WebRTC 泄漏测试。WebRTC 或网站特有检查由原网页和设备 WebView 实际支持能力决定。

### 原创图标

1.2.0 的 [蓝白网络 N 图形](../app/src/main/res/drawable-nodpi/network_toolkit_icon.png) 使用 imagegen 生成，作为本项目原创图形素材。资源提供 Android 自适应启动器前景/背景，以及 Android 13+ 单色主题图标；最终显示遮罩由设备启动器决定。它是网络工具品牌方向的暂定设计，不是从 UISP 页面提取、描摹或使用其 U 标识的图标。

应用实际运行截图保存在 `screenshots/v1.2-*.png`，包括 IP 工具页、网页工具的网络失败提示与启动器实际遮罩。截图、端点测试和现场网站验证是不同证据；当前未完成两个网站所有登录、验证码、收费能力及最新接口的实时验证，实际结果统一见 [VALIDATION.md](VALIDATION.md)。

### 平台与功能边界

- Ping 使用 Android 系统 ICMP，不以 TCP 握手替代。Traceroute 使用递增 TTL 的 ICMP，路由器不回复时显示未响应；不推测丢失的节点、地理位置或运营商。
- DNS 系统默认的 A/AAAA 使用 Android 解析器；其他记录在所选 DNS 上直接走 UDP 53。UDP 查询不继承私密 DNS/DoT，不伪装成 DoH。TTL 仅在实际 DNS 响应提供时显示。
- 分类站点采用 HTTPS HEAD，耗时含连接与服务器响应。界面的绿色/橙色只反映本次实测时间；图片中的毫秒数没有写成应用默认结果。
- 局域网探测可能受 Android、访客网络、防火墙或多播限制漏报。未知 MAC 和厂商不补造；Bonjour/SSDP 只显示实际收到的信息。
- 测速为实际下载和上传。默认约 5 MB 下载 + 1 MB 上传，另有协议开销，与原图约 437 MB 的估算不同；用户确认后才发起测速。
- IP/MAC 显示解析、地址分类、反向 DNS、MAC 格式/OUI 前缀与标志，不附加猜测的归属地、运营商和厂商。
