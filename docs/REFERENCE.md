## 平台与功能边界

- Ping 使用 Android 系统 ICMP，不以 TCP 握手替代。Traceroute 使用递增 TTL 的 ICMP，路由器不回复时显示未响应；不推测丢失的节点、地理位置或运营商。
- DNS 系统默认的 A/AAAA 使用 Android 解析器；其他记录在所选 DNS 上直接走 UDP 53。UDP 查询不继承私密 DNS/DoT，不伪装成 DoH。TTL 仅在实际 DNS 响应提供时显示。
- 分类站点采用 HTTPS HEAD，耗时含连接与服务器响应。界面的绿色/橙色只反映本次实测时间；图片中的毫秒数没有写成应用默认结果。
- 局域网探测可能受 Android、访客网络、防火墙或多播限制漏报。未知 MAC 和厂商不补造；Bonjour/SSDP 只显示实际收到的信息。
- 测速为实际下载和上传。默认约 5 MB 下载 + 1 MB 上传，另有协议开销，与原图约 437 MB 的估算不同；用户确认后才发起测速。
- IP/MAC 显示解析、地址分类、反向 DNS、MAC 格式/OUI 前缀与标志，不附加猜测的归属地、运营商和厂商。
